# SCENE : something

**사진으로 남은 순간을, 글로 남깁니다.**

SCENE : something은 사진과 사용자의 기억을 연결해 **기록·여행기·단편소설**을 만드는 AI 웹 애플리케이션입니다. 사진 속 풍경을 설명하는 데서 나아가, 그때 있었던 일과 느꼈던 마음을 함께 담는 것을 목표로 합니다.

## 프로젝트 소개

사진은 많이 남지만 당시의 경험과 감정은 시간이 지나며 흐려집니다. 그렇다고 매번 빈 페이지에 글을 쓰기에는 부담이 있습니다.

SCENE : something은 사진을 기록의 출발점으로 삼습니다. AI가 사진을 살펴보고 기억과 감정을 묻고, 사용자의 답변을 바탕으로 장면 사이의 이야기를 엮습니다. 같은 사진도 실제 경험을 담은 기록으로 남기거나, 새로운 단편소설의 소재로 사용할 수 있습니다.

## 사용 흐름

1. **사진 올리기** — 사진 3~20장을 선택하고 순서를 정합니다.
2. **기억 떠올리기** — AI가 분석한 사진을 보며 그날의 경험과 감정에 답합니다.
3. **글 설정하기** — 형식, 분위기, 재구성 정도와 챕터 구성을 선택합니다.
4. **이야기 읽기** — 사진과 함께 완성된 글을 읽고, 복사하거나 다시 생성합니다.

모든 질문은 건너뛸 수 있습니다. 개인적인 경험과 생각을 알려줄수록 자신의 기억에 가까운 글을 만들 수 있습니다.

## 주요 기능

### 기록·여행기·소설

| 형식 | 특징 |
| --- | --- |
| 기록 | 경험과 생각을 사용자가 직접 쓴 듯한 자연스러운 글로 구성합니다. 정해진 일기 형식을 강제하지 않습니다. |
| 여행기 | 여행 중의 장소, 이동, 만남과 기억에 남은 순간을 중심으로 구성합니다. |
| 소설 | 사진에서 영감을 받아 인물과 갈등, 전환점과 결말이 있는 단편을 창작합니다. |

소설은 **일상·문학, 로맨스, 미스터리, 판타지, SF, 힐링** 장르를 지원하며, 결과에 AI 창작물임을 표시합니다.

글의 분위기는 **담백하게·감성적으로·영화처럼·문학적으로** 중에서 선택할 수 있습니다.

### 기억과 감정을 묻는 질문

사진의 양과 장면 구성에 따라 질문 수가 달라집니다. 장소나 상황뿐 아니라 당시의 감정, 지금 남은 마음, 그 순간의 의미도 묻습니다. 특정 사진에 대한 질문에는 해당 사진을 함께 보여줍니다.

마지막에는 항상 **“꼭 기록하고 싶은 기억이 있다면 적어주세요.”**라는 질문으로 사진에 드러나지 않은 기억을 남길 수 있습니다.

### 재구성 정도 선택

기록과 여행기에서는 AI가 감정과 생각을 얼마나 보완할지 선택할 수 있습니다. 글의 분위기와는 별도 설정입니다.

| 단계 | 서술 범위 |
| --- | --- |
| 사실 그대로 | 확인된 사실과 직접 입력한 감정·생각을 사용합니다. |
| 가볍게 연결 | 가벼운 느낌과 표현을 조금 보완합니다. 기본 설정입니다. |
| 자연스럽게 재구성 | 장면에 어울리는 감정과 짧은 생각을 더합니다. |
| 풍부하게 표현 | 감정의 흐름과 내적 독백을 풍부하게 구성합니다. |
| 자유롭게 재구성 | 실제 장면을 바탕으로 감정과 성찰을 자유롭게 구성합니다. |

직접 입력한 감정은 모든 단계에서 우선합니다. 기록과 여행기는 재구성 정도가 높아도 외부 사건이나 대화, 인물 관계를 임의로 만들지 않도록 생성 지침을 적용합니다. 감정 보완을 허용한 결과에는 관련 안내를 표시합니다.

소설은 별도의 창작 지침을 사용합니다.

### 사진에 맞춘 챕터 구성

- **자동 구성:** 촬영 시간과 장면 변화에 따라 챕터 수를 유연하게 결정합니다. 확인 가능한 촬영 시간 사이에 24시간 이상 간격이 있으면 챕터를 나눕니다.
- **직접 선택:** 한 챕터에 사진 2~4장이 들어가는 범위에서 챕터 수를 선택합니다. 이때는 자동 시간 분리 규칙보다 선택한 개수를 우선합니다.
- **구성 미리보기:** 생성 전에 챕터별로 어떤 사진이 들어가는지 확인할 수 있습니다.

촬영 시간이 없는 사진의 날짜는 추측하지 않으며, 지정된 사진 순서를 유지합니다.

## AI 활용 방식

AI는 **사진 분석 → 맞춤 질문 → 글 생성**의 흐름에 사용됩니다.

1. **사진 분석:** 분석용으로 압축한 사진에서 장면과 시각적 단서를 파악합니다.
2. **맞춤 질문:** 분석 결과를 바탕으로 사진만으로 알 수 없는 경험과 감정을 묻습니다.
3. **글 생성:** 사진 분석, 사용자 답변, 글 설정을 결합해 선택한 형식으로 작성합니다.

기록 형식은 전체 흐름과 공통 문체 기준을 먼저 계획한 뒤, 두 챕터씩 작성하고 검토합니다. 후반부에서도 시점과 문장 호흡을 유지하고, 글이 단순한 사진 설명으로 바뀌는 것을 줄이기 위한 구조입니다. 문체 예시는 표현 방식을 참고하는 데 사용하며, 예시 속 사건을 사용자의 경험으로 가져오지 않도록 지시합니다.

## 로컬 실행

### 준비 사항

- Node.js **22.13 이상**, npm
- 실제 사진 분석과 글 생성을 위한 OpenAI API 키 및 인터넷 연결

API 키 없이도 샘플 체험을 사용할 수 있습니다. 샘플은 미리 준비된 데이터로 동작하며 실제 AI 생성 결과와는 다릅니다.

### 설치

프로젝트 폴더에서 의존성을 설치합니다.

```sh
npm ci
```

`.env` 파일이 없다면 예시 파일을 복사합니다.

```sh
cp .env.example .env
```

`.env`에 API 키를 입력합니다.

```dotenv
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=gpt-5.4-mini
```

키는 서버에서만 사용합니다. `.env`는 Git 추적 대상에서 제외되며, API 키를 `NEXT_PUBLIC_` 환경 변수에 넣지 않습니다. 위 모델은 이 저장소의 기본 설정입니다.

### 실행

```sh
npm run dev
```

브라우저에서 [localhost:5173](http://localhost:5173)을 엽니다. 실행 주소가 다르면 터미널에 표시된 주소를 사용합니다.

### 검사 및 빌드

```sh
npm run typecheck
npm test
npm run lint
npm run build
```

빌드 결과를 로컬에서 실행하려면 `npm start`를 사용합니다.

## 프로젝트 구조

| 경로 | 역할 |
| --- | --- |
| `app/` | 페이지와 사진 분석·질문·글 생성 API |
| `components/between/` | 사진 배치, 글 설정, 결과 화면 컴포넌트 |

| `lib/images/` | 이미지 압축과 촬영 정보 처리 |
| `lib/openai/` | AI 연결, 프롬프트와 응답 검증 |
| `lib/story/` | 질문, 챕터 구성, 형식·문체별 생성 로직 |
| `lib/demo/` | API 없이 동작하는 샘플 데이터 |
| `tests/` | 입력 검증, 질문·챕터 구성과 생성 흐름 테스트 |

## 이용 시 참고 사항

- **사진 형식:** JPEG·PNG·WebP를 지원하며, 한 장당 최대 30MB까지 올릴 수 있습니다.
- **AI 처리:** 사진의 압축 사본과 생성에 필요한 답변이 서버를 거쳐 OpenAI로 전달됩니다.
- **보관 방식:** 사진·답변·결과를 영구 보관하는 기록함은 없습니다. 새로고침하면 작업이 초기화되므로 필요한 글은 복사해 보관해야 합니다.
- **생성 품질:** AI 결과에는 사실이나 감정 표현의 오류가 있을 수 있습니다. 기억을 구체적으로 입력할수록 개인적인 맥락을 담는 데 도움이 됩니다. 챕터가 많으면 생성 시간과 API 비용이 늘어날 수 있습니다.
